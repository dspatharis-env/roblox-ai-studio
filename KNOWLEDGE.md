# Studio Knowledge

This file stores durable lessons that should influence future work.

## Product principles
- Measure before guessing.
- Optimize the first session and first successful gameplay loop.
- Track where players leave.
- Separate content ideas from validated product decisions.
- Reuse systems only when they reduce complexity.

## Creative principle
Higgsfield expands the visual search space; Roblox Studio reality is the implementation constraint.
