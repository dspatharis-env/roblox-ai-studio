# Roadmap

## Studio objective
Build a portfolio of Roblox experiences with sustainable player growth and Roblox-native revenue.

## Priority order
### M0 — Studio foundation
- Shared repo structure
- Agent operating rules
- Research + analytics loop
- Arena replaces Forest Rescue as the active primary game

### M1 — Arena prototype
- Core round loop
- Spawn / matchmaking flow
- Combat prototype
- First arena
- Basic HUD
- Playtest checklist

### M2 — Arena retention
- Onboarding
- Progression
- Rewards
- Session goals
- Analytics events
- Performance pass

### M3 — Arena monetization
- Roblox-native monetization only
- Fair upgrade/economy design
- Store UX
- Conversion instrumentation
- No external storefront dependency

### M4 — Portfolio expansion
- Steal a Critter
- Sprout Market
- Speed Escape
- Reuse proven studio systems where sensible
