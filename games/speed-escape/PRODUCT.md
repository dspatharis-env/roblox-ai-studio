# Speed Escape Product Strategy

## Core fantasy
"I start slow, learn the route, then become absurdly fast while barely outrunning the wave."

## Differentiation
Avoid a generic +1 speed corridor. Add:
- route decisions
- risky shortcuts
- visible wave phases
- checkpoint recovery
- advanced zones that reward mastery
- satisfying speed/audio/VFX escalation

## First prototype proof
1. movement speed increase is immediately felt
2. wave pressure is readable
3. checkpoint reward is satisfying
4. death/restart time is short
5. speed does not become uncontrollable on mobile

## Monetization caution
A permanent 2x Speed pass can undermine the entire skill/progression curve. Consider convenience/cosmetic value before raw power.
