# Arena

## Status
Primary active game.

## Product promise
Fast, readable, replayable arena battles with clear round goals, progression, rewards, and visually distinct environments.

## Initial core loop
Join -> understand objective -> enter match -> fight/survive/complete objective -> receive reward -> upgrade/unlock -> requeue.

## Design priorities
1. Fast time-to-first-fun
2. Clear combat feedback
3. Short replayable rounds
4. Meaningful progression
5. Strong arena identity
6. Mobile-friendly readability and performance

## Creative direction
Use Higgsfield to explore large imaginative arenas, then reduce concepts into Roblox-feasible environment briefs.
