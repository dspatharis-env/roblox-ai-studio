## Design guardrails
- Longer Lock must not make a paid base effectively unstealable.
- Extra Slots should accelerate collection breadth, not multiply income so aggressively that non-payers cannot compete.
- Pass descriptions must state exact benefits.
- No paid random critter mechanic without separate policy/odds design review.

## Future safer monetization
Prefer:
- cosmetic base themes
- critter display effects
- carry trails
- emotes
- deterministic bundles

## Analytics
Track shop view → item view → prompt → completed purchase, plus retention by pass ownership.
