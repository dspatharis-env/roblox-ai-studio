# Higgsfield — Boop Arena Creative Department

## Scope lock
Higgsfield is currently used **only for Boop Arena**.

Do not spend creative generations on other games until the owner explicitly changes focus.

## What Higgsfield should solve
1. **Identity** — make Boop Arena recognizable at a glance.
2. **Arena imagination** — explore strong environment themes that preserve gameplay readability.
3. **Packaging** — icon, thumbnails and later trailer concepts that truthfully show the game.
4. **Visual feedback** — Boop shockwave, danger/collapse telegraph and win/final-platform moments.

## Recommended Higgsfield model split
Based on the current connected Higgsfield catalog:
- **Recraft V4.1** — preferred for logo/icon exploration and graphic packaging; use vector/utility-vector variants when a clean mark is desired.
- **Soul Location** — preferred for environment/location exploration and arena-theme mood concepts.
- use general stylized image generation only when the composition needs expressive key art rather than graphic/logo precision.

## Core visual language
- bubblegum pink = Boop force/impact
- danger red + non-color cue = collapsing tile warning
- sky blue = openness/background
- grass green = safe lobby
- chunky rounded geometry = friendly party tone
- strong white/dark separation = small-screen readability

## Environment rule
An arena concept is accepted only if it preserves:
- readable walkable boundaries
- fair spawn points
- obvious collapse regions
- simple visual hierarchy during combat
- mobile performance feasibility
- no decorative clutter that hides players or tile state

## ar-03 environment brief
Generate ideas for three mechanically different silhouettes:
1. **Classic Square** — baseline open brawling.
2. **Bridge Cross** — four arms/chokepoints with risky center.
3. **Broken Donut** — perimeter fights and gaps that change escape routes.

Then skin those structures with themes. Theme follows gameplay; theme never defines the layout.

## Icon brief
One large foreground Boop action.
A visible pink shockwave.
One rival sliding toward an edge.
A few red collapse tiles.
Big clean sky separation.
No weapons, no fake mechanics, no crowded collage.

## Thumbnail set
- **Action:** successful Boop at the edge.
- **Collapse:** outer ring falling with players scrambling inward.
- **Final 3x3:** three-player endgame tension.
- **Arena variety:** only after ar-03 is shipped.
- **Cosmetic identity:** only after real cosmetics exist.

## Production flow
brief → 3–8 distinct concepts → select → Roblox feasibility spec → build in Studio → capture real gameplay → adapt final public packaging to remain faithful to the build.
