# Boop Arena Thumbnail Program

## Goal
Create 3–5 truthful 16:9 Home thumbnail variants that test different reasons to click.

## Variants
1. **BOOP** — close-up successful push at the edge.
2. **COLLAPSE** — red outer ring dropping as players sprint inward.
3. **FINAL 3x3** — endgame tension.
4. **ARENA VARIETY** — activate only after ar-03 ships.
5. **COSMETICS** — activate only after cosmetics ship.

## Measurement
For every public variant record:
- asset/version
- start date
- end date
- impressions
- play-through
- first-play bounce guardrail
- interpretation

High click-through with worse bounce is not automatically better.
