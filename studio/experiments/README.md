# Experiment Registry

Create one markdown file per material experiment.

Template:

## Hypothesis
If we change ___ for ___ players, then ___ will improve because ___.

## Primary metric
One metric.

## Guardrails
1–3 metrics that must not materially worsen.

## Variant
Exact version/config/thumbnail/content difference.

## Duration / sample
Record dates and traffic.

## Result
Observed metrics.

## Decision
KEEP / ITERATE / ROLLBACK / INCONCLUSIVE.

Never call a change successful because it "felt better" when analytics are available.
