# Boop Arena Opportunity Queue

During single-game focus, "opportunity" means a Boop Arena improvement, not a new game.

Each opportunity must answer:
- player problem
- proposed change
- why it improves Boop Arena
- metric expected to move
- guardrail metric
- implementation cost
- risk
- test
- rollback

## Current opportunities
- reduce dead time in the 12-second lobby wait
- teach facing/range of Boop without a long tutorial
- make eliminated-player downtime useful
- improve low-player-count pacing
- create arena shapes that change strategy
- turn Coins into desirable fair cosmetics
- create friend/co-play reasons
- improve visual danger cues beyond red color alone
