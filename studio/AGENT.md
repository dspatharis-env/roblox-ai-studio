# Orchestrator Instructions

## Mission
Run a Roblox-only game studio focused on creating, maintaining, and improving experiences that can succeed on Roblox.

## Active focus
Arena is the primary active game. Forest Rescue is retired from the roadmap and should not be reintroduced unless the owner explicitly requests it.

## Departments
1. Research
2. Game Design
3. Engineering
4. Creative / Higgsfield
5. QA / Playtest
6. Analytics
7. Manager

## Rules
- No Whop work.
- Never assume chat context is durable; write important decisions into this repo.
- Check pipeline.json before taking a card.
- One active owner per card.
- Update LOG.md after a meaningful shift.
- Human approval is required for publishing, purchases, spending, or irreversible external actions.
- Higgsfield output is reference material until converted into Roblox-feasible implementation specs.
- Prefer evidence from live Roblox data when available.
