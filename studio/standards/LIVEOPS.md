# LiveOps Standard

## Purpose
Give returning players reasons to come back without turning the game into an exhausting content treadmill.

## Update types
- new arena/map/content
- limited visual event
- progression/cosmetic drop
- balance/QoL patch
- social challenge
- seasonal event

## Event checklist
- real start/end dates
- no fake urgency
- event can be feature-flagged
- analytics event/field identifies event traffic
- update announcement copy is truthful
- rollback plan exists
- post-event cleanup is defined

## Roblox surfaces
Use Experience Events / Updates when the game has a meaningful update worth notifying about. Notifications are scarce attention; do not spam.

## Boop Arena liveops candidates
- rotating arena theme
- weekend "chaos tiles" mode
- cosmetic reward track
- seasonal skybox/lobby decoration
- community milestone unlock

Keep the core boop readable even during events.
