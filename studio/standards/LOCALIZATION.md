# Localization Standard

## Default
Treat all player-facing strings as localizable from the first playable.

## Rules
- centralize reusable UI copy
- avoid concatenated sentences that break grammar in translation
- keep placeholders explicit
- never bake essential instructions/prices into artwork
- keep button copy short
- avoid slang that depends on English unless it is the brand name

## Brand handling
"Boop" can remain a branded mechanic name while its explanatory copy is translated.
"Critter" names can remain proper names, while rarity/shop/tutorial text is localized.

## Rollout
Start with Roblox automatic translation, then manually review high-traffic strings once analytics show language demand.
