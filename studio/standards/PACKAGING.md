# Packaging Standard

## Goal
Maximize qualified play-through, not misleading clicks.

## Icon
- one clear idea at phone size
- 1–2 main subjects
- strong silhouette and contrast
- no tiny text dependency
- no copied competitor logo/layout

## Home thumbnails
Prepare 2–5 active 16:9 variants at 1920x1080 where possible.
Each variant should test a different true promise:
- action
- progression/reward
- social interaction
- world spectacle
- event/update

## Truthfulness gate
Do not show:
- mechanics not shipped
- impossible player counts
- fake rarity/reward outcomes
- visual fidelity completely disconnected from gameplay
- competitor characters/logos

## Text
Use short, legible text only if it adds meaning. The image should still communicate without reading.

## Measurement
Track thumbnail test dates, versions and play-through. Do not permanently crown a winner from tiny traffic.
