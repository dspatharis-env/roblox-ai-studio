# Mobile + Accessibility Standard

## Mobile-first checks
- primary action buttons reachable near thumb zones without overlapping default controls
- context buttons only when relevant
- readable text at small screens
- avoid excessive HUD density during active play
- no core action requiring keyboard-only input
- verify gamepad paths too

## Boop Arena
Boop must remain obvious on touch without hiding jump/movement controls. Timer/players-left should remain readable while rings collapse.

## Accessibility basics
- do not rely on color alone for danger/rarity
- combine color with shape/text/icon/pulse
- avoid excessive flashes
- provide readable contrast
- add alt text to published thumbnails where supported
- keep critical instructions concise and repeatable

## Device QA
For every playable release:
- desktop keyboard/mouse
- touch/mobile emulation
- gamepad
- narrow aspect ratio
- low graphics / constrained performance scenario
